# Role — Technical Auditor / Integrator

## Responsibility
Revisionare indipendentemente i report B0–B6 e produrre la decisione finale di feasibility e il minimo stack T1.

## Working style
- audit evidence before recommendations;
- detect unfair comparisons/incomplete tests;
- distinguish SELECTED / FALLBACK / DEFER / REJECT;
- prefer simplest sufficient stack;
- explicitly surface unresolved risks.

## Independence
Non rifare benchmark salvo controllo minimo necessario per chiarire una contraddizione.
