# Corpus — stato di pubblicazione

Il corpus didattico reale usato per il gate di fattibilità **non è distribuito** in questo
repository. I documenti sorgente, le loro conversioni testuali, i chunk store e i gold set sono
conservati privatamente dal Domain Owner.

| Set | Percorso storico | Stato |
|---|---|---|
| Sorgenti B1 (6 documenti PDF/DOCX/XLSX) | `validation/corpus/source/` | `WITHHELD` |
| Conversioni testuali B1 | `validation/artifacts/B1/` | `WITHHELD` |
| Chunk store B2 | `validation/artifacts/B2/` | `WITHHELD` |
| Gold set e annotazioni umane | `validation/corpus/gold/` | `WITHHELD` |

I report aggregati in `validation/results/` restano come evidenza storica del gate: non
riproducono il testo delle lezioni e non contengono dati personali di studenti.

Politica completa: [`PUBLICATION.md`](../../PUBLICATION.md).

Non reinserire sorgenti, conversioni o gold nel mirror pubblico senza una nuova autorizzazione
esplicita del Domain Owner.
